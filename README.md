# 教务课表 · astrbot_plugin_jw_timetable

从学校教务系统抓真实课表，**上课前按分钟级精度推送提醒**的 AstrBot 插件。

> ✅ **已实测适配：琼台师范学院教务系统**（`jw.qtnu.edu.cn`，强智 jsxsd + 金智统一身份认证 `cas.qtnu.edu.cn`）
> —— SSO 登录、课表解析（65 门课安排全量识别）、学期切换、周次计算均已按该校真实页面验证。
> 学校统一认证地址 `https://cas.qtnu.edu.cn`，SSO 回调地址 `http://jw.qtnu.edu.cn/sso.jsp`。

支持两种最常见的高校登录方式：

| 认证方式 | 适用场景 | 说明 |
|---|---|---|
| **SSO 统一认证** | 学校已禁用教务直连登录（多数高校现状） | 适配金智 `tpass` 体系（CAS 协议），RSA 加密提交，无需验证码 |
| **教务处直连** | 教务系统仍开放登录页 | 适配强智 `jsxsd`，`encoded = b64(学号)+"%%%"+b64(密码)`，需图形验证码 |

`auth_mode: auto`（默认）会先走 SSO，失败自动回落直连。

## 功能

- ⏰ **上课提醒**：默认提前 20 分钟，可设第二档（如再提前 5 分钟补一次）
- ✏️ **面板编辑课表**：在 WebUI 里添加/编辑/删除自定义课程（班会、自习等），也能按条隐藏教务课程；自定义课程参与上课提醒、早报和 LLM 查询，教务刷新不会覆盖
- 🤖 **LLM 工具**：已注册 `kb_query_day_schedule` / `kb_query_week_timetable` / `kb_query_next_class` / `kb_query_status` 四个 function-calling 工具，直接在对话里问「今天有什么课」「下节课是什么」即可
- 🖥 **WebUI 面板**：在 AstrBot 网页端直接查看周课表、切换周数、填账号、一键刷新
- ☀️ **每日早报**：每天固定时间推当天课表，当天没课可以不打扰
- 🔔 **变更推送**：调课、换教室、换教师、停课被检测到就推一条
- 📅 **随时查询**：今日 / 明日 / 指定周 / 指定星期，支持 `/课表` 中文指令
- 🖼 **课表图片**：整周课表用文转图渲染成表格图，失败自动回退文字
- 🔁 **会话复用**：cookie 落盘，重启免登录；失效自动重登
- 🧩 **多目标推送**：私聊与群聊可分别开关

## 安装

1. 在 AstrBot WebUI 的「插件」页面安装本插件，或把仓库克隆到 `data/plugins/`：
   ```bash
   cd AstrBot/data/plugins
   git clone https://github.com/QianKunBoss/astrbot_plugin_jw_timetable
   ```
2. 重启 AstrBot（或在 WebUI 里重载插件）。依赖会自动安装：
   `httpx` / `beautifulsoup4` / `lxml` / `cryptography` / `tzdata`
3. 打开插件配置，填写 `jw` 分组。

> 只用直连登录且需要自动识别验证码时，再额外执行 `pip install ddddocr`；
> Docker 部署还需要 `apt-get install -y libgl1 libglib2.0-0`。
> 走 SSO 登录则**不需要** ddddocr。

## 配置

### jw · 教务系统连接

| 项 | 说明 |
|---|---|
| `base_url` | 教务地址，如 `http://jw.example.edu.cn`（**不要**带 `/jsxsd`） |
| `auth_mode` | `auto` / `sso` / `direct` |
| `cas_url` | 统一认证地址，如 `https://cas.example.edu.cn`；留空则不走 SSO |
| `service_url` | SSO 回调地址；留空自动用 `base_url + /jsxsd/sso.jsp`。填错时可从浏览器 SSO 地址栏的 `service=` 参数抄 |
| `username` / `password` | 学号与密码（密码仅存于 AstrBot 配置文件） |
| `ssl_verify` | 个别学校 CAS 证书过期时关闭 |
| `captcha_ocr` | 直连登录是否需要自动识别验证码 |

**怎么找这几个地址？**

1. 浏览器打开教务系统，如果被跳到统一认证登录页，地址栏就是 `cas_url`；
2. 跳转地址里的 `?service=` 参数（URL 解码后）就是 `service_url`；
3. 登录后进入课表页，地址里的主机部分就是 `base_url`。

### schedule · 学期与作息

| 项 | 说明 |
|---|---|
| `term` | `auto` 跟随教务默认学期，也可写 `2026-2027-1` |
| `week1_monday` | 第 1 周周一。留空自动从教务页面「当前周」反推 |
| `periods` | 作息时间表（JSON）。留空用内置 12 节默认值，**建议首次使用后核对** |
| `refresh_hours` | 课表自动刷新间隔，默认 6 小时 |

作息可用指令微调：`/kb period show` → `/kb period set 3 10:00-10:45`

### notify · 提醒

| 项 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 总开关 |
| `ahead_minutes` | 20 | 提前多少分钟提醒 |
| `second_ahead_minutes` | 0 | 第二档提醒，0 = 关闭 |
| `daily_brief_time` | 07:00 | 每日早报时间，留空/`off` 关闭 |
| `brief_skip_empty` | true | 当天没课不发早报 |
| `notify_on_change` | true | 课表变动推送 |
| `max_sends_per_minute` | 3 | 限频，防止聊天平台风控 |

### push · 推送目标

两种方式任选：

- **WebUI**：在 `push.private_umos` / `push.group_umos` 里直接选择会话；
- **指令**：在被推送的私聊/群里发 `/kb push here`，自动写入配置。

## WebUI 面板

安装后，在 AstrBot 网页端「插件」里找到本插件，点插件卡片进入详情页即可打开「教务课表面板」；
它也会出现在侧边栏的扩展功能入口里。

面板包含三页：

| 页面 | 内容 |
|---|---|
| **课表** | 节次 × 星期 的表格，按周切换（‹ › / 回到本周），当天那一列高亮，底部列出「今天接下来的课」 |
| **设置** | 教务地址、认证方式、统一认证地址、回调地址、学号密码、提醒参数、AI 补全开关，保存即写入插件配置 |
| **状态** | 登录方式、当前周与第 1 周来源、课表缓存时间、推送目标数，以及识别质量（缺教师/缺教室/周次靠猜的条数） |

顶部两个按钮：**刷新课表**（重新登录并抓取）、**测试登录**（只验证凭据，不抓表）；
`提醒` 开关对应 `notify.enabled`，点一下立即生效。

> 面板基于 AstrBot 的插件视图能力（`views/` + `register_web_api`），需要 v4.28 及以上；
> 更低版本会自动跳过面板注册，其余功能正常。
> 0.3.3 起面板**始终可用**，不再有启用/关闭开关（历史配置里的 `web` 分组会被忽略）。

### 关于「智能识别」

强智各校模板差异大，有些课表单元格没有 `<font title="老师">` 这类结构化标签。
默认走启发式规则（周次、教室、教师按特征归类）；如果仍认不全，可在设置里打开
**「用 AI 补全课程名 / 教师 / 教室」**，插件会把认不出的原始文本交给 AstrBot 已配置的模型
再抽取一次。

- 只处理缺教师或缺教室的课程，已完整的不会重复消耗 token；
- 结果按原文哈希缓存，同一份课表刷新多次也只调用一次；
- 补全写回同一份 `Course` 数据，所以**面板表格和推送文案用的是同一份结果**；
- 模型不可用或报错时静默降级为规则结果，不影响刷新。

## 工作原理

```
每分钟 tick
   ├─ 课表过期？（默认 6 小时）→ 登录 → 抓课表 → 解析 → 落盘 → diff 变更
   ├─ 今天第几周？（第1周周一 + 今天）
   ├─ 遍历今天剩余的课
   │    └─ 0 < (上课时间 - 现在) <= 提前分钟数，且未提醒过 → 推送并落盘
   └─ 到早报时间且当天未发 → 推送当日课表
```

刻意**没有**用「每节课挂一个定时任务」的方案：课表一变（调课/换教室）挂死的任务立刻失配，
插件重启还要全部重建。改成每分钟计算一次，是幂等的——重启、改表、系统时间跳变都能自愈，
去重靠 `notified.json` 落盘保证。

### 文件落在哪

全部在 `data/plugin_data/astrbot_plugin_jw_timetable/`：

| 文件 | 内容 |
|---|---|
| `session.json` | cookie（不含密码），带账号指纹，换账号自动作废 |
| `timetable.json` | 最近一次课表缓存 |
| `notified.json` | 已推送记录（3 天滚动） |
| `snapshots/` | 课表原始 HTML 快照，改版排障用 |

## 首次接入建议流程

如果登录/解析失败，先用探针脚本把问题定位在「认证」还是「解析」：

```bash
python tools/probe_jw.py \
  --base-url http://jw.example.edu.cn \
  --cas-url https://cas.example.edu.cn \
  --username 2026xxxx
# 密码用环境变量传入，避免留在 shell 历史
# export JW_PASSWORD='******'
```

产物在 `probe_out/`：`xskb_*.html`（原始页面）、`timetable.json`（解析结果）、`probe.log`。
退出码：`0` 成功 / `2` 配置 / `3` 网络 / `4` 认证 / `5` 解析。

## 常见问题

**Q：提示「统一认证拒绝了回调地址：未认证授权的服务」？**
A：`service_url` 必须与浏览器登录时跳转地址**逐字符一致**。最常见两种错法：
① 少了 `http://`（填成 `jw.xxx.edu.cn/...` 或 `/jw.xxx.edu.cn/...`）；
② 教务是 `http://` 却写成了 `https://`。
CAS 只认注册过的那个地址，差一个字符都会返回「未认证授权的服务」。
从浏览器地址栏里 `?service=` 后面那段**URL 解码**后原样填进来即可。

**Q：日志出现「统一认证登录页缺少 lt 字段」？**
A：说明 CAS 返回的不是登录页（多半就是上面的 service 未授权，或学校换了登录页模板）。
即使出现这句也会自动退避 30 分钟不再重试，不会反复打扰学校服务器。把该行日志发给作者即可定位。

**Q：提示「统一认证已通过，但教务系统未接受票据」？**
A：该校 SSO 回调地址可能不是 `/jsxsd/sso.jsp`。用浏览器登录一次，看 CAS 跳回教务时地址栏的
`service=` 参数，把它解码后填进 `service_url`（要填完整 URL，含 `http://`）。

**Q：验证码一直识别失败？**
A：`ddddocr` 没装或 Docker 缺 `libgl1`。另一种办法是改用 SSO 登录——多数学校 SSO 无验证码。

**Q：提醒时间不对 / 早了晚了一节课？**
A：作息表没对齐。`/kb period show` 看内置值，用 `/kb period set 3 10:00-10:45` 逐条改正。

**Q：当前周数不对？**
A：`/kb status` 里看「来源」。显示 `guessed` 说明是按学期估算的，用
`/kb week1 2026-09-07` 填本学期第 1 周的周一即可。

**Q：收不到提醒？**
A：按顺序排查——`/kb status` 看「推送目标」是否为 0（为 0 就去目标会话发 `/kb push here`）、
`/kb notify on` 是否开启、群里是否开了 `group_enabled`。

**Q：教务系统改版了？**
A：解析器不依赖固定 class/id，但大改版仍可能失效。把 `snapshots/` 里最新的 HTML（脱敏后）提 issue，
通常只需补一条字段识别规则。

**Q：改了 WebUI 配置要重启吗？**
A：指令修改的配置立即生效；WebUI 里保存后建议重载一次插件，确保新配置被读取。

## 隐私与安全

- 密码只保存在 AstrBot 自己的配置文件里（`data/config/` 下），插件不会写入日志、不会上传任何第三方；
- 日志中的账号一律脱敏为 `1234****78`；
- 本地只缓存 cookie 与课表，`session.json` 带账号指纹，换账号自动失效；
- 插件只访问你在配置里填写的教务与统一认证地址。

## 已知限制

- 只实现了强智 `jsxsd` 与金智 `tpass` 两类系统，其他厂商（正方 / URP / 青果）暂不支持；
- 一个账号绑定多身份（学生 + 教工）时，CAS 会要求选择身份，此时会明确报错而不是乱猜；
- 节假日调休不会自动处理——教务系统课表本身不含调休信息，如需要可手动 `/kb notify off` 一天；
- 课表以周为单位，单双周、`1-16周` 这类都能正确识别，但「临时借用教室」类通知不在教务数据里。
